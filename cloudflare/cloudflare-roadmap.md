# Cloudflare Developer Roadmap: Fundamentals → Intermediate

> General knowledge for DevOps engineers, with Cloudflare-specific context.

## Platform Basics (Prerequisites)

- [ ] **Phase 1** — What is Cloudflare: network, products, edge computing
- [ ] **Phase 2** — Account setup: plans, orgs, members, permissions
- [ ] **Phase 3** — Zones & domains: adding, verification, zone states
- [ ] **Phase 4** — Dashboard & APIs: console navigation, API tokens

## DNS & Networking

- [ ] **Phase 5** — DNS management: records, proxied vs gray cloud
- [ ] **Phase 6** — DNS best practices: TTLs, records, migration
- [ ] **Phase 7** — DDoS protection: layers, detection, mitigations
- [ ] **Phase 8** — Load Balancing: pools, monitors, steering
- [ ] **Phase 9** — Network routing: Argo, smart routing, tunnels
- [ ] **Phase 10** — IP & firewall: IP lists, firewall rules, geo filtering

## CDN & Caching

- [ ] **Phase 11** — Caching basics: cache types, browser vs edge cache
- [ ] **Phase 12** — Cache rules: cache everything, bypass, TTLs
- [ ] **Phase 13** — Cache keys: custom keys, device types, language
- [ ] **Phase 14** — Purge & invalidation: purge by URL, cache tags
- [ ] **Phase 15** — Image optimization: resizing, compression, delivery

## Security

- [ ] **Phase 16** — WAF: managed rules, custom rules, rule groups
- [ ] **Phase 17** — Rate limiting: thresholds, actions, tokens
- [ ] **Phase 18** — Bot management: bot scores, challenges, bot fight mode
- [ ] **Phase 19** — SSL/TLS: modes, certificates, full vs flexible
- [ ] **Phase 20** — Page rules & transform rules: behavior, headers
- [ ] **Phase 21** — Zero Trust basics: identity, policies, enforcement

## Workers

- [ ] **Phase 22** — Workers basics: runtime, requests, responses
- [ ] **Phase 23** — Worker development: Wrangler, local dev, deploy
- [ ] **Phase 24** — KV storage: reads, writes, consistency
- [ ] **Phase 25** — Durable Objects: state, storage, coordination
- [ ] **Phase 26** — Scheduled tasks: cron triggers, batch jobs
- [ ] **Phase 27** — Workers integrations: R2, AI, Queues, bindings

## Pages

- [ ] **Phase 28** — Pages deployment: static sites, builds, branches
- [ ] **Phase 29** — Pages Functions: serverless handlers, routing
- [ ] **Phase 30** — Preview & staging: preview deployments, aliases
- [ ] **Phase 31** — CI integration: git providers, build configs

## Storage & Data

- [ ] **Phase 32** — R2: object storage, S3 compatibility, presigned URLs
- [ ] **Phase 33** — D1: SQLite database, migrations, queries
- [ ] **Phase 34** — Queues: producers, consumers, retries, dead letter

## Observability & Operations

- [ ] **Phase 36** — Logs: HTTP logs, Workers logs, log push
- [ ] **Phase 37** — Analytics: dashboards, zones, traffic insights
- [ ] **Phase 38** — Workers observability: traces, metrics, errors
- [ ] **Phase 39** — Alerts: notification services, thresholds

## Zero Trust & Access

- [ ] **Phase 40** — Access: applications, policies, SSO integration
- [ ] **Phase 41** — Tunnels: Cloudflare Tunnel, no public IPs
- [ ] **Phase 42** — Gateway: DNS filtering, HTTP filtering

## Career & Practice

- [ ] **Phase 44** — Architecture patterns: edge-first design, reference stacks
- [ ] **Phase 45** — Cost optimization: plans, usage, egress
- [ ] **Phase 46** — Portfolio: edge apps, integrations, case studies
- [ ] **Phase 47** — Interview prep: platform concepts, scenario questions

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Platform basics
2. **Phase 5–10** — DNS & networking
3. **Phase 11–15** — CDN & caching
4. **Phase 16–21** — Security
5. **Phase 22–27** — Workers
6. **Phase 28–31** — Pages
7. **Phase 40–43** — Zero Trust
