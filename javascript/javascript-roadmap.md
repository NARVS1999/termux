# JavaScript Developer Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with JavaScript-specific context.

## Language Basics (Prerequisites)

- [ ] **Phase 1** — Syntax & variables: let/const/var, naming, statements
- [ ] **Phase 2** — Data types: primitives, objects, typeof, conversions
- [ ] **Phase 3** — Operators & coercion: arithmetic, comparison, logical, implicit casts
- [ ] **Phase 4** — Control flow: if/else, switch, loops, break/continue
- [ ] **Phase 5** — Functions basics: declarations, expressions, parameters, returns

## Functions & Scope

- [ ] **Phase 6** — Scope & hoisting: global, function, block scope, TDZ
- [ ] **Phase 7** — Closures: captured variables, module patterns
- [ ] **Phase 8** — this binding: call, apply, bind, context rules
- [ ] **Phase 9** — Arrow functions: lexical this, concise bodies, limits
- [ ] **Phase 10** — Higher-order functions: callbacks, map/filter/reduce, composition

## Objects & Prototypes

- [ ] **Phase 11** — Objects: literals, properties, methods, shorthand
- [ ] **Phase 12** — Prototypes: prototype chains, inheritance, Object.create
- [ ] **Phase 13** — Classes: constructors, inheritance, static, private fields
- [ ] **Phase 14** — Property descriptors: getters/setters, enumerability, freezing
- [ ] **Phase 15** — Symbols & iterators: well-known symbols, iteration protocol

## Arrays & Collections

- [ ] **Phase 16** — Array methods: iteration, transformation, searching
- [ ] **Phase 17** — Destructuring & spread: arrays, objects, rest patterns
- [ ] **Phase 18** — Set & Map: uniqueness, keyed access, use cases
- [ ] **Phase 19** — Nested & sparse arrays: flattening, holes, copying

## Async Programming

- [ ] **Phase 20** — Callbacks: patterns, pyramid of doom, conventions
- [ ] **Phase 21** — Promises: states, chaining, Promise.all/race/allSettled
- [ ] **Phase 22** — async/await: syntax, error handling, parallel execution
- [ ] **Phase 23** — Event loop: call stack, microtasks, macrotasks, rendering
- [ ] **Phase 24** — Timers & scheduling: setTimeout, setInterval, requestAnimationFrame
- [ ] **Phase 25** — Async patterns: retries, timeouts, cancellation, concurrency limits

## DOM & Browser APIs

- [ ] **Phase 26** — DOM selection & traversal: queries, walking, properties
- [ ] **Phase 27** — DOM manipulation: create, insert, remove, attributes
- [ ] **Phase 28** — Events: listeners, bubbling/capturing, delegation, preventDefault
- [ ] **Phase 29** — Forms & inputs: values, validation, FormData
- [ ] **Phase 30** — Storage: localStorage, sessionStorage, cookies, IndexedDB
- [ ] **Phase 31** — Fetch & AJAX: requests, headers, errors, uploads

## Modern ES6+ Features

- [ ] **Phase 32** — Template literals: interpolation, tagged templates
- [ ] **Phase 33** — Modules: import/export, default vs named, dynamic import
- [ ] **Phase 34** — Optional chaining & nullish coalescing: safe access, defaults
- [ ] **Phase 35** — Modern syntax: shorthand, computed keys, object spread
- [ ] **Phase 36** — Generators & iterators: yield, protocols, async generators

## Error Handling & Debugging

- [ ] **Phase 37** — try/catch/finally: throwing, rethrowing, types
- [ ] **Phase 38** — Custom errors: Error subclasses, error metadata
- [ ] **Phase 39** — Debugging: console, breakpoints, watch, profiling
- [ ] **Phase 40** — Common pitfalls: NaN, ==, mutation, closures in loops

## Tooling & Ecosystem

- [ ] **Phase 41** — npm: packages, scripts, versions, publishing basics
- [ ] **Phase 42** — Bundlers: Vite, webpack, esbuild, tree shaking
- [ ] **Phase 43** — Linting & formatting: ESLint, Prettier, configs
- [ ] **Phase 44** — Testing: Jest/Vitest, assertions, mocking, coverage

## Career & Practice

- [ ] **Phase 45** — Project structure: files, organization, conventions
- [ ] **Phase 46** — Code quality: readability, refactoring, reviews
- [ ] **Phase 47** — Interview prep: coding challenges, behaviorals, system basics

## Recommended Learning Path (priority order)

1. **Phase 1–5** — Language basics
2. **Phase 6–10** — Functions & scope
3. **Phase 20–25** — Async programming
4. **Phase 26–31** — DOM & browser APIs
5. **Phase 11–15** — Objects & prototypes
6. **Phase 32–36** — Modern features
7. **Phase 41–44** — Tooling & testing

> Focus on building real projects — employers hire mid-level JavaScript devs for clean, performant, well-tested code plus ownership of features end-to-end.
