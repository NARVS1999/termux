# Next.js Week Developer Roadmap: Fundamentals

> General knowledge for frontend developers, with Next.js-specific context.

## React & Web Prerequisites

- [ ] **Phase 1** — React basics: components, props, state, events
- [ ] **Phase 2** — React hooks: useState, useEffect, custom hooks
- [ ] **Phase 3** — JavaScript & TypeScript: types, async, modules
- [ ] **Phase 4** — Web fundamentals: HTTP, rendering, browser APIs

## Next.js Fundamentals

- [ ] **Phase 5** — What is Next.js: App Router, SSR, SSG, full-stack framework
- [ ] **Phase 6** — create-next-app: setup, templates, configuration
- [ ] **Phase 7** — Project structure: app folder, conventions, metadata
- [ ] **Phase 8** — Dev experience: hot reload, dev tools, debugging

## Routing

- [ ] **Phase 9** — File-based routing: routes, files, page conventions
- [ ] **Phase 10** — Dynamic routes: params, catch-all, generateStaticParams
- [ ] **Phase 11** — Layouts: nested layouts, templates, route groups
- [ ] **Phase 12** — Loading & error states: loading files, error boundaries
- [ ] **Phase 13** — Linking & navigation: Link, useRouter, prefetching

## Rendering

- [ ] **Phase 14** — Server vs client components: boundaries, directives
- [ ] **Phase 15** — Server-side rendering: dynamic data, cookies, headers
- [ ] **Phase 16** — Static generation: prerendering, static params
- [ ] **Phase 17** — Streaming & suspense: partial loading, fallbacks

## Data Fetching

- [ ] **Phase 18** — Server data fetching: async components, fetch patterns
- [ ] **Phase 19** — Server Actions: mutations, forms, progressive enhancement
- [ ] **Phase 20** — Client fetching: SWR, TanStack Query, effects
- [ ] **Phase 21** — Mutations & invalidation: revalidation, optimistic updates

## Styling & UI

- [ ] **Phase 22** — CSS Modules: scoped styles, composition
- [ ] **Phase 23** — Tailwind CSS: utility classes, config, responsive
- [ ] **Phase 24** — Global styles & themes: variables, dark mode
- [ ] **Phase 25** — Fonts & images: next/font, next/image, optimization

## Forms & Validation

- [ ] **Phase 26** — Forms with Server Actions: actions, pending states
- [ ] **Phase 27** — Validation: client and server validation, errors
- [ ] **Phase 28** — Form error handling: field errors, global errors

## Deployment Basics

- [ ] **Phase 29** — Environment config: env vars, secrets, .env files
- [ ] **Phase 30** — Deployment: Vercel, build process, previews

## Recommended Learning Path (priority order)

1. **Phase 5** — What is Next.js and the App Router
2. **Phase 9** — File-based routing basics
3. **Phase 14** — Server vs client components
4. **Phase 18** — Server data fetching patterns
5. **Phase 6** — create-next-app setup
6. **Phase 23** — Tailwind CSS styling
7. **Phase 19** — Server Actions for forms

> Focus on building real projects — employers hire mid-level frontend devs for clean, performant, well-tested code plus ownership of features end-to-end.
