# Product Designer Roadmap: Fundamentals → Intermediate

> General knowledge for designers, with product-design-specific context.

## Design Fundamentals (Prerequisites)

- [ ] **Phase 1** — Design thinking: empathy, define, ideate, prototype, test
- [ ] **Phase 2** — Visual design basics: shape, contrast, balance, rhythm, emphasis
- [ ] **Phase 3** — Typography: type anatomy, hierarchy, pairing, legibility
- [ ] **Phase 4** — Color theory: color models, palettes, contrast, psychology

## User Research

- [ ] **Phase 5** — Research methods: generative vs evaluative, qualitative vs quantitative
- [ ] **Phase 6** — Interviews: scripting, moderation, note-taking, synthesis
- [ ] **Phase 7** — Surveys: question design, sampling, bias avoidance
- [ ] **Phase 8** — Personas: creation, scenarios, adoption in design
- [ ] **Phase 9** — Jobs-to-be-done: user jobs, motivations, outcome expectations

## UX & Interaction Design

- [ ] **Phase 10** — UX principles: discoverability, feedback, mapping, constraints
- [ ] **Phase 11** — Information architecture: organization, labeling, navigation, sitemaps
- [ ] **Phase 12** — User flows: task flows, journey maps, decision points
- [ ] **Phase 13** — Wireframing: low-fi layouts, annotations, hierarchy
- [ ] **Phase 14** — Interaction design: states, transitions, feedback loops

## UI Design

- [ ] **Phase 15** — Visual hierarchy: scanning patterns, focal points, order
- [ ] **Phase 16** — Layout & grids: grid systems, breakpoints, responsive layouts
- [ ] **Phase 17** — Spacing & alignment: 8pt system, rhythm, alignment rules
- [ ] **Phase 18** — Iconography: icon styles, grids, meaning, consistency
- [ ] **Phase 19** — Imagery & illustration: sourcing, style, composition
- [ ] **Phase 20** — Motion & micro-interactions: easing, duration, purpose

## Prototyping

- [ ] **Phase 21** — Fidelity levels: low, mid, high-fidelity tradeoffs
- [ ] **Phase 22** — Prototyping tools: Figma, prototyping modes, components
- [ ] **Phase 23** — Clickable prototypes: flows, transitions, assets
- [ ] **Phase 24** — Responsive prototypes: breakpoints, device frames
- [ ] **Phase 25** — Prototype testing: tasks, observation, iteration loops

## Design Systems

- [ ] **Phase 26** — Design tokens: colors, type, spacing, semantic naming
- [ ] **Phase 27** — Components: anatomy, variants, states, composition
- [ ] **Phase 28** — Documentation: usage guidelines, do/don't, examples
- [ ] **Phase 29** — Versioning: change logs, release notes, adoption
- [ ] **Phase 30** — Governance: contribution, review, evolution process

## Usability & Testing

- [ ] **Phase 31** — Usability heuristics: Nielsen's heuristics, common violations
- [ ] **Phase 32** — Usability testing: moderation, tasks, metrics (SUS, task success)
- [ ] **Phase 33** — A/B testing: hypothesis, variants, statistical basics
- [ ] **Phase 34** — Analytics-informed design: funnels, heatmaps, session data

## Accessibility & Inclusive Design

- [ ] **Phase 35** — WCAG: levels, success criteria, conformance
- [ ] **Phase 36** — Inclusive design: ability spectrum, edge personas
- [ ] **Phase 37** — Accessibility testing: screen readers, keyboard, tools
- [ ] **Phase 38** — Accessible visuals: contrast, type scaling, focus states

## Collaboration & Product Skills

- [ ] **Phase 39** — Working with PMs & engineers: requirements, constraints, handoff
- [ ] **Phase 40** — Design critique: giving/receiving feedback, critique sessions
- [ ] **Phase 41** — Stakeholder communication: presenting, buy-in, decisions
- [ ] **Phase 42** — Product metrics: KPIs, impact measurement, iteration
- [ ] **Phase 43** — Design handoff: specs, assets, dev-ready files

## Portfolio & Career

- [ ] **Phase 44** — Case studies: problem framing, process, outcomes
- [ ] **Phase 45** — Portfolio building: selection, presentation, storytelling
- [ ] **Phase 46** — Personal brand: presence, writing, community
- [ ] **Phase 47** — Interview prep: portfolio reviews, whiteboard challenges, culture

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Design fundamentals
2. **Phase 5–9** — User research
3. **Phase 10–14** — UX & interaction design
4. **Phase 15–20** — UI design
5. **Phase 21–25** — Prototyping
6. **Phase 31–34** — Usability & testing
7. **Phase 44–47** — Portfolio & career

> Focus on building real projects — employers hire mid-level product designers for clean, usable, well-tested products plus ownership of experiences end-to-end.
