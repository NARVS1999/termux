# Cyber Security Engineer Roadmap: Fundamentals → Intermediate

> General knowledge for security engineers, with cyber-security-specific context.

## Fundamentals (Prerequisites)

- [ ] **Phase 1** — Networking basics: OSI model, TCP/IP, DNS, ports, protocols
- [ ] **Phase 2** — OS fundamentals: Windows & Linux, processes, filesystems, permissions
- [ ] **Phase 3** — Linux for security: command line, users, logs, scripting
- [ ] **Phase 4** — Core security concepts: CIA triad, attack surface, defense in depth

## Network Security

- [ ] **Phase 5** — Firewalls: rules, zones, stateful vs stateless, next-gen firewalls
- [ ] **Phase 6** — VPNs & tunneling: IPsec, WireGuard, remote access, split tunneling
- [ ] **Phase 7** — IDS/IPS: signatures, anomaly detection, bypasses
- [ ] **Phase 8** — Segmentation: VLANs, microsegmentation, network zoning
- [ ] **Phase 9** — Protocol security: DNS, DHCP, TLS, email security (SPF/DKIM/DMARC)
- [ ] **Phase 10** — Wireless security: WPA2/WPA3, rogue APs, attacks

## Cryptography

- [ ] **Phase 11** — Symmetric encryption: AES, modes, block vs stream ciphers
- [ ] **Phase 12** — Asymmetric encryption: RSA, ECC, Diffie-Hellman, signatures
- [ ] **Phase 13** — Hashing: SHA family, HMAC, password storage, salting
- [ ] **Phase 14** — PKI & TLS: certificates, CAs, handshake, certificate pinning
- [ ] **Phase 15** — Key management: lifecycle, HSMs, rotation, crypto attacks

## Web & Application Security

- [ ] **Phase 16** — OWASP Top 10: overview, risk impact, mitigations
- [ ] **Phase 17** — Injection attacks: SQLi, command injection, NoSQL injection
- [ ] **Phase 18** — XSS & CSRF: stored, reflected, DOM, token defenses
- [ ] **Phase 19** — Auth & session flaws: broken auth, session fixation, OAuth misconfigs
- [ ] **Phase 20** — SSRF & file issues: SSRF, path traversal, upload abuse
- [ ] **Phase 21** — Secure coding & supply chain: sanitization, dependency risks, SBOM

## System Security

- [ ] **Phase 22** — OS hardening: baselines, CIS benchmarks, services, configs
- [ ] **Phase 23** — Endpoint security: EDR, antivirus, application allowlisting
- [ ] **Phase 24** — Patch management: vulnerability windows, patching cadence
- [ ] **Phase 25** — Malware analysis basics: static vs dynamic, sandboxes, triage
- [ ] **Phase 26** — Privilege management: least privilege, UAC/sudo, LAPS

## Cloud & Infrastructure Security

- [ ] **Phase 27** — Cloud security models: shared responsibility, provider tools
- [ ] **Phase 28** — IAM in cloud: roles, policies, federation, conditional access
- [ ] **Phase 29** — Container security: image scanning, runtime, RBAC, seccomp
- [ ] **Phase 30** — IaC security: misconfig scanning, secrets, drift detection
- [ ] **Phase 31** — Identity security: SSO, MFA, privileged access management

## Security Operations

- [ ] **Phase 32** — SOC operations: monitoring, triage, escalation, shifts
- [ ] **Phase 33** — SIEM: log sources, correlation rules, dashboards
- [ ] **Phase 34** — Incident response: detection, containment, eradication, recovery
- [ ] **Phase 35** — Forensics: evidence handling, timelines, disk/memory analysis
- [ ] **Phase 36** — Threat intelligence: feeds, IoCs, TTPs, attribution
- [ ] **Phase 37** — Vulnerability management: scanning, prioritization, remediation
- [ ] **Phase 38** — Purple teaming: detection validation, exercises

## Penetration Testing

- [ ] **Phase 39** — Reconnaissance: passive, active, OSINT, enumeration
- [ ] **Phase 40** — Scanning: port scanning, service detection, vulnerabilities
- [ ] **Phase 41** — Exploitation: metasploit, manual techniques, weaponization
- [ ] **Phase 42** — Post-exploitation: persistence, lateral movement, privilege escalation
- [ ] **Phase 43** — Reporting: findings, severity, remediation guidance

## Compliance & Risk

- [ ] **Phase 44** — Frameworks: NIST, ISO 27001, SOC 2, PCI DSS, GDPR
- [ ] **Phase 45** — Audits: evidence, controls testing, gap analysis
- [ ] **Phase 46** — Risk management: risk registers, scoring, acceptance
- [ ] **Phase 47** — Privacy: data classification, PII handling, breach response

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Fundamentals
2. **Phase 5–10** — Network security
3. **Phase 16–21** — Web security
4. **Phase 11–15** — Cryptography
5. **Phase 32–38** — Security operations
6. **Phase 39–43** — Penetration testing
7. **Phase 44–47** — Compliance & risk

> Focus on building real projects — employers hire mid-level security engineers for clean, hardened, well-monitored systems plus ownership of security end-to-end.
