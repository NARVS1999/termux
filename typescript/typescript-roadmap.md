# TypeScript Developer Roadmap: Fundamentals → Intermediate

> General knowledge for frontend developers, with TypeScript-specific context.

## TypeScript Basics (Prerequisites)

- [ ] **Phase 1** — Setup: installing, tsc, build pipelines, IDE support
- [ ] **Phase 2** — Type annotations: variables, parameters, returns, object shapes
- [ ] **Phase 3** — Primitives & inference: number, string, boolean, inference rules
- [ ] **Phase 4** — Special types: any, unknown, never, void, null/undefined
- [ ] **Phase 5** — tsconfig: strict mode, targets, modules, include/exclude

## Types & Interfaces

- [ ] **Phase 6** — Object types: inline shapes, nested, optional and readonly
- [ ] **Phase 7** — Interfaces: extends, declaration merging, use cases
- [ ] **Phase 8** — Type aliases: unions, intersections, composite types
- [ ] **Phase 9** — Union & narrowing: typeof, in, discriminated unions, exhaustiveness
- [ ] **Phase 10** — Structural typing: assignability, excess property checks

## Functions

- [ ] **Phase 11** — Parameter types: annotations, optional, defaults, rest
- [ ] **Phase 12** — Return types: inference, explicit, void functions
- [ ] **Phase 13** — Function types: signatures, callbacks, method signatures
- [ ] **Phase 14** — Overloads: multiple signatures, implementation
- [ ] **Phase 15** — Generics basics: generic functions, inference, constraints

## Advanced Types

- [ ] **Phase 16** — Generics deep: defaults, variance, multiple params
- [ ] **Phase 17** — keyof & typeof: indexed access, type queries
- [ ] **Phase 18** — Mapped types: transformation, modifiers, filtering
- [ ] **Phase 19** — Conditional types: inference, distributive behavior
- [ ] **Phase 20** — Template literal types: string patterns, parsing
- [ ] **Phase 21** — Utility types: Partial, Pick, Omit, Record, ReturnType

## Classes & OOP

- [ ] **Phase 22** — Classes: fields, constructors, parameter properties
- [ ] **Phase 23** — Access modifiers: public, private, protected, readonly
- [ ] **Phase 24** — Abstract classes: abstract members, design uses
- [ ] **Phase 25** — Implements: interface contracts, multiple interfaces
- [ ] **Phase 26** — Decorators & mixins: class decorators, composition patterns

## Modules & Project Structure

- [ ] **Phase 27** — ES modules: import/export, re-exports, side effects
- [ ] **Phase 28** — Declaration files: .d.ts, ambient declarations, typings
- [ ] **Phase 29** — Module resolution: paths, bundlers, nodeNext
- [ ] **Phase 30** — Path aliases: baseUrl, paths, consistency
- [ ] **Phase 31** — Project references: composite projects, build orchestration

## TypeScript in Practice

- [ ] **Phase 32** — DOM typing: events, elements, typed queries
- [ ] **Phase 33** — Async typing: promises, async/await, callbacks
- [ ] **Phase 34** — Error handling: typed errors, unknown catches, result types
- [ ] **Phase 35** — Environment typing: env vars, process.env, global types
- [ ] **Phase 36** — Strict mode: strictNullChecks, noImplicitAny, fixes
- [ ] **Phase 37** — Data modeling: API responses, unions for states, validation

## Framework Integration

- [ ] **Phase 38** — React + TS: components, props, hooks typing
- [ ] **Phase 39** — Generic components: typing complex props, refs
- [ ] **Phase 40** — Context & providers: typed context, consumers
- [ ] **Phase 41** — Node.js + TS: runtime types, imports, configs
- [ ] **Phase 42** — API typing: request/response types, shared contracts

## Tooling & Quality

- [ ] **Phase 43** — tsconfig mastery: target, lib, module settings
- [ ] **Phase 44** — ESLint + TS: parser, rules, type-aware linting
- [ ] **Phase 45** — Type testing: expect-type, compile-time assertions
- [ ] **Phase 46** — Migration: JS to TS strategies, incremental conversion
- [ ] **Phase 47** — Docs & references: TypeScript handbook, community patterns

## Recommended Learning Path (priority order)

1. **Phase 1–5** — TypeScript basics
2. **Phase 6–10** — Types & interfaces
3. **Phase 11–15** — Functions & generics
4. **Phase 16–21** — Advanced types
5. **Phase 38–42** — Framework integration
6. **Phase 32–37** — TS in practice
7. **Phase 43–47** — Tooling & quality

> Focus on building real projects — employers hire mid-level TypeScript devs for clean, type-safe, well-tested code plus ownership of features end-to-end.
