# Frontend Developer Roadmap: Fundamentals → Intermediate

> General knowledge for frontend developers, with frontend-specific context.

## Internet & Web Fundamentals (Prerequisites)

- [ ] **Phase 1** — How the web works: HTTP & HTTPS, request-response cycle, status codes, headers
- [ ] **Phase 2** — DNS & domain names: resolution, records (A, CNAME, MX), CDNs
- [ ] **Phase 3** — Browsers: rendering engine, DOM, CSSOM, rendering pipeline, network panel
- [ ] **Phase 4** — Web basics: URLs, cookies, sessions, same-origin policy, local vs session storage

## HTML & CSS

- [ ] **Phase 5** — HTML semantics: semantic tags, headings, forms, accessibility attributes
- [ ] **Phase 6** — CSS selectors & cascade: specificity, inheritance, cascade layers, combinators
- [ ] **Phase 7** — Box model & layout: box-sizing, Flexbox, CSS Grid, floats, positioning
- [ ] **Phase 8** — Responsive design: media queries, mobile-first, fluid layouts, breakpoints
- [ ] **Phase 9** — Modern CSS: custom properties, functions, animations, transitions, transforms
- [ ] **Phase 10** — CSS preprocessors: Sass/SCSS, nesting, mixins, partials, variables

## JavaScript Fundamentals

- [ ] **Phase 11** — JS basics: variables, data types, operators, type coercion, strict mode
- [ ] **Phase 12** — Functions & scope: declarations vs expressions, closures, hoisting, this
- [ ] **Phase 13** — Arrays & objects: methods, iteration, destructuring, spread/rest
- [ ] **Phase 14** — DOM manipulation & events: querySelector, createElement, event listeners, delegation
- [ ] **Phase 15** — ES6+ features: template literals, arrow functions, classes, modules, optional chaining
- [ ] **Phase 16** — Async JS: promises, async/await, fetch, error handling, event loop

## JavaScript Ecosystem & Tooling

- [ ] **Phase 17** — npm & packages: package.json, dependencies, scripts, semver
- [ ] **Phase 18** — Build tools: Vite, Webpack, esbuild, HMR, bundling basics
- [ ] **Phase 19** — Transpilation & linting: Babel, ESLint, Prettier, editor config
- [ ] **Phase 20** — Git basics: init, clone, commit, branch, merge, push/pull

## Styling Approaches & Frameworks

- [ ] **Phase 21** — Tailwind CSS: utility-first, config, responsive utilities, dark mode
- [ ] **Phase 22** — CSS Modules: scoped styles, composition, typed styles
- [ ] **Phase 23** — CSS-in-JS: styled-components, theming, dynamic styles, pitfalls
- [ ] **Phase 24** — Component libraries: MUI, shadcn/ui, Ant Design, headless components

## Frontend Frameworks

- [ ] **Phase 25** — React basics: JSX, components, props, state, events
- [ ] **Phase 26** — React hooks: useState, useEffect, useRef, custom hooks
- [ ] **Phase 27** — Vue basics: templates, reactivity, composition API, directives
- [ ] **Phase 28** — Angular basics: components, modules, services, signals
- [ ] **Phase 29** — Framework choice: ecosystem, learning curve, project fit, SSR support

## State Management & Routing

- [ ] **Phase 30** — Client-side routing: React Router, Vue Router, lazy routes
- [ ] **Phase 31** — Local & global state: context, lifting state, when to avoid global state
- [ ] **Phase 32** — State libraries: Zustand, Redux Toolkit, Pinia, Jotai
- [ ] **Phase 33** — Server state: TanStack Query, SWR, caching, invalidation, mutations

## Testing & Quality

- [ ] **Phase 34** — Unit testing: Vitest/Jest, setup, assertions, mocking, coverage
- [ ] **Phase 35** — Component testing: Testing Library, userEvent, screen queries
- [ ] **Phase 36** — E2E testing: Playwright, Cypress, test scenarios, CI integration
- [ ] **Phase 37** — Debugging: browser devtools, breakpoints, performance profiler, source maps

## Performance & Web Security

- [ ] **Phase 38** — Core Web Vitals: LCP, INP, CLS, measuring with Lighthouse
- [ ] **Phase 39** — Code splitting: dynamic imports, lazy loading, bundle analysis
- [ ] **Phase 40** — Caching & assets: HTTP caching, service workers, image optimization
- [ ] **Phase 41** — Web security: XSS, CSRF, CSP, CORS, sanitization, HTTPS

## Deployment & Modern Frontend

- [ ] **Phase 42** — Static hosting: Vercel, Netlify, GitHub Pages, preview deployments
- [ ] **Phase 43** — CI/CD basics: GitHub Actions, build pipelines, automated deploys
- [ ] **Phase 44** — Environment & config: env vars, feature flags, secrets management
- [ ] **Phase 45** — Monitoring & analytics: error tracking (Sentry), web analytics, alerts
- [ ] **Phase 46** — Progressive Web Apps: manifest, service workers, offline support
- [ ] **Phase 47** — Accessibility: ARIA, keyboard navigation, WCAG, contrast, screen readers

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Internet & web fundamentals
2. **Phase 5–10** — HTML & CSS
3. **Phase 11–16** — JavaScript fundamentals
4. **Phase 17–20** — Tooling & git
5. **Phase 25–26** — React basics & hooks
6. **Phase 30–33** — Routing & state management
7. **Phase 34–37** — Testing & debugging

> Focus on building real projects — employers hire mid-level frontend devs for clean, performant, well-tested code plus ownership of features end-to-end.
