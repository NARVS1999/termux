# iOS Developer Roadmap: Fundamentals → Intermediate

> General knowledge for mobile developers, with iOS-specific context.

## Swift & Language Fundamentals (Prerequisites)

- [ ] **Phase 1** — Swift basics: variables, constants, types, control flow, optionals
- [ ] **Phase 2** — Collections: arrays, dictionaries, sets, iteration, map/filter/reduce
- [ ] **Phase 3** — Functions & closures: parameters, guards, closures, higher-order usage
- [ ] **Phase 4** — Protocols & generics: protocol conformance, extensions, generic functions
- [ ] **Phase 5** — Error handling: throws, do/catch, Result, error propagation

## Xcode & Tooling

- [ ] **Phase 6** — Xcode basics: project navigation, editors, debugger, playgrounds
- [ ] **Phase 7** — Project structure: targets, frameworks, assets, Info.plist
- [ ] **Phase 8** — Build configuration: schemes, build phases, signing, Swift packages
- [ ] **Phase 9** — Simulators & devices: running, testing on device, provisioning

## iOS Fundamentals (UIKit)

- [ ] **Phase 10** — UIKit basics: views, controls, layout, Auto Layout
- [ ] **Phase 11** — View controllers: lifecycle, view management, containment
- [ ] **Phase 12** — Table & collection views: data sources, delegates, cells, diffing
- [ ] **Phase 13** — App lifecycle: states, scenes, app delegate, launch flows
- [ ] **Phase 14** — Navigation: navigation controllers, tabs, sheets, transitions
- [ ] **Phase 15** — Gestures & input: gesture recognizers, keyboard handling, focus

## SwiftUI

- [ ] **Phase 16** — SwiftUI basics: views, modifiers, stacks, spacing
- [ ] **Phase 17** — State management: @State, @Binding, @ObservableObject, @Environment
- [ ] **Phase 18** — Lists & navigation: List, NavigationStack, navigation values
- [ ] **Phase 19** — Forms & controls: TextField, Picker, Toggle, validation
- [ ] **Phase 20** — Custom views: view composition, drawing, animation
- [ ] **Phase 21** — UIKit interop: UIViewRepresentable, hosting controllers

## Data & Persistence

- [ ] **Phase 22** — UserDefaults & settings: simple storage, defaults domains
- [ ] **Phase 23** — Codable: encoding/decoding, key strategies, nested models
- [ ] **Phase 24** — Core Data: models, fetch requests, relationships, contexts
- [ ] **Phase 25** — SwiftData: models, queries, migrations, iCloud sync
- [ ] **Phase 26** — Files & documents: FileManager, security-scoped access, caches

## Networking & Concurrency

- [ ] **Phase 27** — URLSession: requests, tasks, error handling, decoding
- [ ] **Phase 28** — Async/await: async functions, tasks, cancellation, actors
- [ ] **Phase 29** — Combine basics: publishers, subjects, pipelines, operators
- [ ] **Phase 30** — Image loading: SDWebImage/Kingfisher, caching, placeholders
- [ ] **Phase 31** — Background work: background tasks, URLSession background, pushes

## Architecture & Patterns

- [ ] **Phase 32** — MVVM: models, view models, bindings, testing
- [ ] **Phase 33** — Repository & service layers: data sources, abstractions
- [ ] **Phase 34** — Dependency injection: manual DI, containers, factories
- [ ] **Phase 35** — Navigation patterns: coordinators, deep linking, flows
- [ ] **Phase 36** — Modularization: frameworks, features, app boundaries

## Testing & Quality

- [ ] **Phase 37** — Unit testing: XCTest, async tests, mocking, coverage
- [ ] **Phase 38** — UI testing: XCUITest, accessibility identifiers, flows
- [ ] **Phase 39** — Snapshot & preview tests: reference images, regression
- [ ] **Phase 40** — Profiling: Instruments, allocations, time profiler, leaks

## Performance & Best Practices

- [ ] **Phase 41** — Memory: retain cycles, weak references, autoreleasepool
- [ ] **Phase 42** — Launch & responsiveness: launch time, main thread, throttling
- [ ] **Phase 43** — Accessibility: VoiceOver, dynamic type, labels
- [ ] **Phase 44** — App Store guidelines: review policies, privacy, data collection

## Publishing & Distribution

- [ ] **Phase 45** — Signing & certificates: developer accounts, profiles, capabilities
- [ ] **Phase 46** — App Store Connect: listings, screenshots, pricing, review
- [ ] **Phase 47** — Releases: TestFlight, staged rollouts, versioning, crash monitoring

## Recommended Learning Path (priority order)

1. **Phase 1–5** — Swift fundamentals
2. **Phase 10–15** — UIKit essentials
3. **Phase 16–21** — SwiftUI
4. **Phase 27–31** — Networking & concurrency
5. **Phase 32–36** — Architecture patterns
6. **Phase 37–40** — Testing & quality
7. **Phase 45–47** — Publishing

> Focus on building real projects — employers hire mid-level iOS devs for clean, performant, well-tested code plus ownership of features end-to-end.
