# Machine Learning Engineer Roadmap: Fundamentals → Intermediate

> General knowledge for data engineers, with machine-learning-specific context.

## Prerequisites

- [ ] **Phase 1** — Python basics: variables, types, control flow, functions, error handling
- [ ] **Phase 2** — Math essentials: linear algebra, vectors, matrices, dot products
- [ ] **Phase 3** — Calculus & probability: derivatives, gradients, distributions, expected value
- [ ] **Phase 4** — Data tooling: git, Jupyter notebooks, environments, reproducibility

## Python for ML

- [ ] **Phase 5** — numpy: arrays, broadcasting, vectorized ops, random generation
- [ ] **Phase 6** — pandas: DataFrames, filtering, grouping, joins, missing data
- [ ] **Phase 7** — Visualization: matplotlib, seaborn, plots for data exploration
- [ ] **Phase 8** — scikit-learn basics: estimators, fit/predict, pipelines, preprocessing
- [ ] **Phase 9** — Data loading: CSV/JSON/Parquet, sampling, dataset splits

## Statistics & Probability

- [ ] **Phase 10** — Descriptive stats: mean, median, variance, percentiles, outliers
- [ ] **Phase 11** — Distributions: normal, binomial, Poisson, skewness, kurtosis
- [ ] **Phase 12** — Hypothesis testing: p-values, confidence intervals, A/B testing
- [ ] **Phase 13** — Probability concepts: Bayes theorem, conditional probability, independence

## Machine Learning Fundamentals

- [ ] **Phase 14** — Learning types: supervised, unsupervised, semi-supervised, reinforcement
- [ ] **Phase 15** — Data splits: train/validation/test, cross-validation, leakage
- [ ] **Phase 16** — Regression: MSE/MAE, R-squared, residuals, regularization
- [ ] **Phase 17** — Classification: precision, recall, F1, ROC-AUC, confusion matrix
- [ ] **Phase 18** — Overfitting: bias-variance tradeoff, regularization, early stopping

## Core ML Algorithms

- [ ] **Phase 19** — Linear & logistic regression: coefficients, interpretation, assumptions
- [ ] **Phase 20** — Decision trees & ensembles: random forests, bagging, boosting
- [ ] **Phase 21** — SVM: margins, kernels, hyperparameters
- [ ] **Phase 22** — KNN & instance methods: distances, k selection, scaling sensitivity
- [ ] **Phase 23** — Clustering & reduction: k-means, hierarchical, PCA, t-SNE

## Deep Learning

- [ ] **Phase 24** — Neural networks: neurons, layers, forward pass, loss functions
- [ ] **Phase 25** — Backpropagation: gradients, learning rates, weight init
- [ ] **Phase 26** — CNNs: convolutions, pooling, architectures, transfer learning
- [ ] **Phase 27** — Sequence models: RNNs, LSTMs, attention, transformers
- [ ] **Phase 28** — Training practices: optimizers, dropout, batch norm, scheduling
- [ ] **Phase 29** — Frameworks: PyTorch basics, TensorFlow/Keras, GPU training

## Feature Engineering

- [ ] **Phase 30** — Cleaning: missing values, outliers, duplicates, type fixes
- [ ] **Phase 31** — Encoding: one-hot, label, ordinal, target encoding
- [ ] **Phase 32** — Scaling & transforms: standardization, normalization, log/power
- [ ] **Phase 33** — Feature selection: importance, correlation, dimensionality, creation

## Model Deployment

- [ ] **Phase 34** — Model serving: pickle/ONNX, endpoints, latency considerations
- [ ] **Phase 35** — Serving APIs: FastAPI/REST, batching, versioning models
- [ ] **Phase 36** — Containerization: Docker images, GPU images, resource limits
- [ ] **Phase 37** — Monitoring: drift detection, data quality, retraining triggers
- [ ] **Phase 38** — MLOps: experiment tracking, registries, CI for models, pipelines

## Specialized Areas

- [ ] **Phase 39** — NLP basics: tokenization, stop words, TF-IDF, text classification
- [ ] **Phase 40** — Embeddings: word vectors, sentence embeddings, similarity search
- [ ] **Phase 41** — LLM basics: prompt structure, fine-tuning, RAG patterns
- [ ] **Phase 42** — Computer vision: image loading, augmentation, object detection
- [ ] **Phase 43** — Time series: trends, seasonality, lag features, forecasting basics

## Career & Practices

- [ ] **Phase 44** — Portfolio projects: end-to-end ML projects, reproducibility
- [ ] **Phase 45** — Documentation: experiment notes, model cards, READMEs
- [ ] **Phase 46** — Communication: presenting results, stakeholder translation
- [ ] **Phase 47** — Ethics & bias: fairness, explainability, responsible AI

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Prerequisites
2. **Phase 5–9** — Python for ML
3. **Phase 14–18** — ML fundamentals
4. **Phase 19–23** — Core algorithms
5. **Phase 24–29** — Deep learning
6. **Phase 34–38** — Deployment & MLOps
7. **Phase 44–47** — Projects & practices

> Focus on building real projects — employers hire mid-level ML engineers for clean, reproducible, well-tested models plus ownership of features end-to-end.
