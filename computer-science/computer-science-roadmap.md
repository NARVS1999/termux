# Computer Science Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with computer-science-specific context.

## Programming Fundamentals (Prerequisites)

- [ ] **Phase 1** — Programming basics: variables, types, control flow, functions
- [ ] **Phase 2** — OOP: classes, objects, inheritance, polymorphism, encapsulation
- [ ] **Phase 3** — Functional basics: immutability, pure functions, higher-order functions
- [ ] **Phase 4** — Tooling: editors, terminals, git, debugging basics

## Data Structures

- [ ] **Phase 5** — Arrays & strings: indexing, slicing, two-pointer patterns
- [ ] **Phase 6** — Linked lists: singly, doubly, cycles, reversing
- [ ] **Phase 7** — Stacks & queues: LIFO/FIFO, implementations, monotonic stacks
- [ ] **Phase 8** — Hash tables: hashing, collisions, load factor, design
- [ ] **Phase 9** — Trees: binary trees, BSTs, traversals, heaps
- [ ] **Phase 10** — Graphs: representations, traversals (BFS/DFS), weighted graphs

## Algorithms

- [ ] **Phase 11** — Complexity analysis: Big-O, time vs space, growth rates
- [ ] **Phase 12** — Searching: linear, binary, interpolation, search trees
- [ ] **Phase 13** — Sorting: comparison sorts, quicksort/mergesort, stability
- [ ] **Phase 14** — Recursion & backtracking: base cases, state, pruning
- [ ] **Phase 15** — Greedy algorithms: exchange arguments, applicability
- [ ] **Phase 16** — Dynamic programming: memoization, tabulation, subproblems

## Computer Architecture

- [ ] **Phase 17** — Number systems: binary, hex, two's complement, floats
- [ ] **Phase 18** — CPU & memory: registers, ALU, RAM, buses
- [ ] **Phase 19** — Instruction execution: fetch-decode-execute, assembly basics
- [ ] **Phase 20** — Caching & pipelining: cache hierarchy, locality, hazards

## Operating Systems

- [ ] **Phase 21** — Processes & threads: creation, states, context switching
- [ ] **Phase 22** — Scheduling: algorithms, priorities, fairness
- [ ] **Phase 23** — Memory management: paging, segmentation, virtual memory
- [ ] **Phase 24** — File systems: inodes, directories, permissions
- [ ] **Phase 25** — Concurrency: synchronization, locks, deadlocks, semaphores

## Computer Networks

- [ ] **Phase 26** — Networking stack: OSI/TCP-IP layers, encapsulation
- [ ] **Phase 27** — IP & routing: addressing, subnets, routing protocols
- [ ] **Phase 28** — Transport protocols: TCP, UDP, handshakes, reliability
- [ ] **Phase 29** — Application layer: HTTP, DNS, TLS, email protocols
- [ ] **Phase 30** — Network security: firewalls, encryption, attacks

## Databases

- [ ] **Phase 31** — Relational model: tables, keys, relationships
- [ ] **Phase 32** — SQL: queries, joins, aggregations, normalization
- [ ] **Phase 33** — Indexing: B-trees, query plans, tradeoffs
- [ ] **Phase 34** — Transactions: ACID, isolation levels, concurrency control

## Theory of Computation

- [ ] **Phase 35** — Automata: DFAs, NFAs, regular languages
- [ ] **Phase 36** — Context-free languages: grammars, pushdown automata
- [ ] **Phase 37** — Computability: Turing machines, decidability, NP-completeness

## Software Engineering

- [ ] **Phase 38** — SDLC: requirements, design, implementation, testing, ops
- [ ] **Phase 39** — Testing: unit, integration, TDD, coverage
- [ ] **Phase 40** — Design patterns: common patterns and when to use them
- [ ] **Phase 41** — Version control: branching, merging, collaboration
- [ ] **Phase 42** — Code quality: readability, refactoring, review

## Math & Problem Solving

- [ ] **Phase 43** — Discrete math: sets, relations, functions, induction
- [ ] **Phase 44** — Linear algebra: vectors, matrices, transformations
- [ ] **Phase 45** — Probability: events, distributions, expected values
- [ ] **Phase 46** — Logic: propositions, predicates, proofs
- [ ] **Phase 47** — Problem solving: patterns, practice, contests

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Programming fundamentals
2. **Phase 5–10** — Data structures
3. **Phase 11–16** — Algorithms
4. **Phase 21–25** — Operating systems
5. **Phase 26–30** — Computer networks
6. **Phase 31–34** — Databases
7. **Phase 43–47** — Math & problem solving

> Focus on building real projects — employers hire mid-level software engineers for clean, efficient, well-tested code plus ownership of features end-to-end.
