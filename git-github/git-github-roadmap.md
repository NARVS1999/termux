# Git & GitHub Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with git-specific context.

## Git Fundamentals (Prerequisites)

- [ ] **Phase 1** — What is git: version control, snapshots, distributed model
- [ ] **Phase 2** — Setup: install, config, identity, aliases, editors
- [ ] **Phase 3** — Repositories: init, clone, working tree, .git structure
- [ ] **Phase 4** — Staging & committing: add, commit, messages, atomic commits
- [ ] **Phase 5** — File states: tracked, modified, staged, ignored files
- [ ] **Phase 6** — .gitignore: patterns, exceptions, global ignores

## Branching & Merging

- [ ] **Phase 7** — Branches: creating, switching, listing, naming
- [ ] **Phase 8** — Merging: fast-forward, three-way, merge commits
- [ ] **Phase 9** — Merge conflicts: causes, resolution, strategies
- [ ] **Phase 10** — Rebase: interactive, when to use, golden rule
- [ ] **Phase 11** — Cherry-pick & tags: selective commits, version tags

## Remotes & Collaboration

- [ ] **Phase 12** — Remotes: adding, viewing, upstream tracking
- [ ] **Phase 13** — Sync: push, pull, fetch, pull vs fetch
- [ ] **Phase 14** — Pull requests: opening, reviewing, merging
- [ ] **Phase 15** — Forks: workflows, sync with upstream
- [ ] **Phase 16** — Remote branches: tracking, pruning, deleting
- [ ] **Phase 17** — Collaboration etiquette: commit hygiene, descriptions

## History & Debugging

- [ ] **Phase 18** — Log: formats, filters, graph views, authors
- [ ] **Phase 19** — Diff: staged vs unstaged, comparing branches
- [ ] **Phase 20** — Blame: finding changes, annotations
- [ ] **Phase 21** — Bisect: binary search for bugs, automation
- [ ] **Phase 22** — Reflog: reference history, recovery paths

## Stashing & Cleanup

- [ ] **Phase 23** — Stash: saving, applying, popping, branches
- [ ] **Phase 24** — Clean: untracked files, removal safety
- [ ] **Phase 25** — Reset vs revert: moving, undoing, keeping history
- [ ] **Phase 26** — Maintenance: pruning, gc, repository hygiene

## GitHub Features

- [ ] **Phase 27** — Issues: templates, labels, milestones, triage
- [ ] **Phase 28** — Projects: boards, views, automation
- [ ] **Phase 29** — Actions basics: workflows, events, jobs
- [ ] **Phase 30** — Pages: static sites, deployment
- [ ] **Phase 31** — Gists & snippets: sharing, embedding
- [ ] **Phase 32** — Discussions & wiki: community, docs

## Advanced Git

- [ ] **Phase 33** — Hooks: client hooks, enforcement, husky
- [ ] **Phase 34** — Submodules & subtrees: nested repos, tradeoffs
- [ ] **Phase 35** — Worktrees: parallel checkouts, isolation
- [ ] **Phase 36** — LFS: large files, pointers, bandwidth
- [ ] **Phase 37** — Rerere: conflict reuse, repeat merges

## Workflows & Team Practices

- [ ] **Phase 38** — Workflows: GitFlow, trunk-based, feature branches
- [ ] **Phase 39** — Conventional commits: types, scopes, changelogs
- [ ] **Phase 40** — Code review etiquette: feedback, approvals, CI gates
- [ ] **Phase 41** — Release management: tags, branches, hotfixes
- [ ] **Phase 42** — Security: SSH keys, tokens, signed commits

## Undoing & Recovery

- [ ] **Phase 43** — Fixing commits: amend, edit messages
- [ ] **Phase 44** — Undoing merges: revert merge, conflict resolution
- [ ] **Phase 45** — Recovering work: reflog, orphaned commits, stash
- [ ] **Phase 46** — Rewriting history: rebase -i, filter-branch, risks
- [ ] **Phase 47** — Force push: when safe, protections, alternatives

## Recommended Learning Path (priority order)

1. **Phase 1–6** — Git fundamentals
2. **Phase 7–11** — Branching & merging
3. **Phase 12–17** — Remotes & collaboration
4. **Phase 18–22** — History & debugging
5. **Phase 38–42** — Workflows & team practices
6. **Phase 27–32** — GitHub features
7. **Phase 43–47** — Undoing & recovery

> Focus on building real projects — employers hire mid-level developers for clean, well-versioned, collaborative code plus ownership of features end-to-end.
