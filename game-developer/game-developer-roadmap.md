# Game Developer Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with game-development-specific context.

## Programming Fundamentals (Prerequisites)

- [ ] **Phase 1** — Programming basics: C# or C++, variables, control flow, functions
- [ ] **Phase 2** — OOP: classes, inheritance, interfaces, composition
- [ ] **Phase 3** — Data structures: arrays, lists, dicts, queues, trees
- [ ] **Phase 4** — Algorithms: sorting, searching, recursion, complexity
- [ ] **Phase 5** — Math for games: vectors, matrices, trigonometry, transforms

## Game Engines

- [ ] **Phase 6** — Engine overview: Unity vs Unreal, editor layout, projects
- [ ] **Phase 7** — Scenes & objects: GameObjects, components, transforms, prefabs
- [ ] **Phase 8** — Assets: import pipelines, materials, textures, bundles
- [ ] **Phase 9** — Editor workflows: inspector, hierarchy, scene building
- [ ] **Phase 10** — Version control for games: Git LFS, branching, merge conflicts

## Gameplay Programming

- [ ] **Phase 11** — Game loop: update, fixed timestep, frame rates
- [ ] **Phase 12** — Input handling: keyboard, mouse, gamepad, touch
- [ ] **Phase 13** — Movement & physics: velocity, gravity, rigidbodies, forces
- [ ] **Phase 14** — Collisions: colliders, triggers, raycasts, layers
- [ ] **Phase 15** — Spawning & pooling: object pooling, instantiate, lifecycle
- [ ] **Phase 16** — Game states: state machines, scene transitions, pause

## Game Design

- [ ] **Phase 17** — Core loops: mechanics, loops, fun factors
- [ ] **Phase 18** — Level design: pacing, structure, player guidance
- [ ] **Phase 19** — Game balancing: tuning, difficulty curves, progression
- [ ] **Phase 20** — Player psychology: rewards, feedback, engagement
- [ ] **Phase 21** — Prototyping: paper prototypes, vertical slices, iteration

## Graphics & Rendering

- [ ] **Phase 22** — 3D fundamentals: meshes, transforms, world vs local space
- [ ] **Phase 23** — Cameras & lighting: projection, lights, shadows
- [ ] **Phase 24** — Materials & shaders: basics, textures, PBR, shader graphs
- [ ] **Phase 25** — 2D rendering: sprites, animations, sorting layers
- [ ] **Phase 26** — Performance: draw calls, batching, level of detail

## Audio & UI

- [ ] **Phase 27** — Audio integration: clips, sources, mixers, 3D audio
- [ ] **Phase 28** — Sound design: SFX, ambience, music implementation
- [ ] **Phase 29** — Game UI: menus, HUD, inventory, screen space
- [ ] **Phase 30** — UI/UX design: readability, feedback, accessibility

## Physics & AI

- [ ] **Phase 31** — Physics engines: rigidbody dynamics, constraints, joints
- [ ] **Phase 32** — Raycasting & queries: linecasts, overlaps, targeting
- [ ] **Phase 33** — Pathfinding: A*, navmeshes, movement agents
- [ ] **Phase 34** — NPC behavior: behavior trees, finite state machines, utility AI
- [ ] **Phase 35** — Procedural generation: noise, dungeons, worlds

## Multiplayer & Networking

- [ ] **Phase 36** — Networking models: client-server, peer-to-peer, authority
- [ ] **Phase 37** — Matchmaking & sessions: lobbies, rooms, invites
- [ ] **Phase 38** — Synchronization: snapshots, interpolation, lag compensation
- [ ] **Phase 39** — Backend services: accounts, leaderboards, cloud saves

## Testing & Quality

- [ ] **Phase 40** — Playtesting: sessions, feedback, iteration
- [ ] **Phase 41** — Debugging: breakpoints, logs, profilers
- [ ] **Phase 42** — Performance profiling: frame times, memory, GC
- [ ] **Phase 43** — Automated testing: unit tests, integration, CI builds

## Publishing & Career

- [ ] **Phase 44** — Builds & platforms: PC, console, mobile, web builds
- [ ] **Phase 45** — Store publishing: Steam, app stores, ratings, updates
- [ ] **Phase 46** — Monetization: pricing, DLC, live ops basics
- [ ] **Phase 47** — Portfolio & jobs: game jams, demos, industry hiring

## Recommended Learning Path (priority order)

1. **Phase 1–5** — Programming fundamentals
2. **Phase 6–10** — Game engines
3. **Phase 11–16** — Gameplay programming
4. **Phase 17–21** — Game design
5. **Phase 22–26** — Graphics & rendering
6. **Phase 40–43** — Testing & quality
7. **Phase 44–47** — Publishing & career

> Focus on building real projects — employers hire mid-level game devs for clean, performant, well-tested code plus ownership of features end-to-end.
