# AI Product Builder Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with AI-product-specific context.

## AI Fundamentals (Prerequisites)

- [ ] **Phase 1** — AI concepts: machine learning, deep learning, generative AI
- [ ] **Phase 2** — ML basics: training, inference, models, datasets
- [ ] **Phase 3** — LLM concepts: pretraining, fine-tuning, capabilities
- [ ] **Phase 4** — Capabilities & limits: hallucinations, knowledge cutoff, reasoning

## LLMs & Models

- [ ] **Phase 5** — Transformer basics: attention, tokens, layers
- [ ] **Phase 6** — Model types: chat, instruct, reasoning, multimodal
- [ ] **Phase 7** — Context windows: sizes, limits, long-context strategies
- [ ] **Phase 8** — Tokens: tokenization, pricing, counting, batching
- [ ] **Phase 9** — Model selection: quality, cost, latency, provider choices

## Prompting & Context Engineering

- [ ] **Phase 10** — Prompt basics: system, user, assistant messages
- [ ] **Phase 11** — Advanced prompting: chain-of-thought, few-shot, structured output
- [ ] **Phase 12** — Context design: relevant info, compression, ordering
- [ ] **Phase 13** — Prompt patterns: personas, templates, constraints
- [ ] **Phase 14** — Output control: JSON mode, schemas, validation

## RAG

- [ ] **Phase 15** — Retrieval basics: chunks, retrieval, grounding
- [ ] **Phase 16** — Embeddings & vector DBs: similarity search, indexes
- [ ] **Phase 17** — Chunking: strategies, overlap, metadata
- [ ] **Phase 18** — Hybrid search: keyword + vector, reranking
- [ ] **Phase 19** — RAG evaluation: relevance, groundedness, recall

## Agents & Tools

- [ ] **Phase 20** — Tool use: function calling, schemas, execution
- [ ] **Phase 21** — Agent loops: planning, acting, observing
- [ ] **Phase 22** — Memory: conversation, long-term, state
- [ ] **Phase 23** — Multi-agent patterns: roles, orchestration, handoffs
- [ ] **Phase 24** — Frameworks: LangChain, LangGraph, OpenAI tools

## Evaluation

- [ ] **Phase 25** — Eval design: use cases, criteria, datasets
- [ ] **Phase 26** — Metrics: accuracy, latency, cost, quality scores
- [ ] **Phase 27** — Test sets: golden sets, synthetic data, edge cases
- [ ] **Phase 28** — Human evaluation: side-by-side, feedback loops

## Data & Infrastructure

- [ ] **Phase 29** — Data preparation: cleaning, formatting, PII removal
- [ ] **Phase 30** — Vector store operations: ingestion, updates, backups
- [ ] **Phase 31** — Pipelines: extraction, transformation, indexing
- [ ] **Phase 32** — API integration: providers, SDKs, retries, streaming
- [ ] **Phase 33** — Cost & latency: caching, model routing, quantization

## Product Thinking

- [ ] **Phase 34** — Use case selection: feasibility, value, differentiation
- [ ] **Phase 35** — UX for AI: streaming, feedback, uncertainty
- [ ] **Phase 36** — Guardrails: input/output filters, safety layers
- [ ] **Phase 37** — Privacy & compliance: data handling, disclosures
- [ ] **Phase 38** — Monetization: pricing, usage, packaging

## Building & Shipping

- [ ] **Phase 39** — Architecture patterns: pipeline, agent, RAG stacks
- [ ] **Phase 40** — Prototyping: quick demos, iteration, user tests
- [ ] **Phase 41** — Frontend integration: chat UI, streaming, states
- [ ] **Phase 42** — Launch: rollout, feedback loops, versioning
- [ ] **Phase 43** — Monitoring: quality drift, logs, incident response

## Ethics & Career

- [ ] **Phase 44** — Responsible AI: bias, transparency, misuse
- [ ] **Phase 45** — Safety: content policies, red teaming basics
- [ ] **Phase 46** — Career paths: builder roles, specializations
- [ ] **Phase 47** — Portfolio: shipped AI products, case studies

## Recommended Learning Path (priority order)

1. **Phase 1–4** — AI fundamentals
2. **Phase 5–9** — LLMs & models
3. **Phase 10–14** — Prompting
4. **Phase 15–19** — RAG
5. **Phase 20–24** — Agents & tools
6. **Phase 34–38** — Product thinking
7. **Phase 44–47** — Ethics & career

> Focus on building real projects — employers hire mid-level AI product builders for clean, reliable, well-evaluated products plus ownership of features end-to-end.
