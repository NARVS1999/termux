# Prompt Engineering Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with prompt-engineering-specific context.

## LLM Fundamentals (Prerequisites)

- [ ] **Phase 1** — How LLMs work: prediction, training, fine-tuning
- [ ] **Phase 2** — Tokens: tokenization, counts, pricing, limits
- [ ] **Phase 3** — Model types: chat, instruct, reasoning, multimodal
- [ ] **Phase 4** — Context windows: sizes, constraints, long-context tactics
- [ ] **Phase 5** — Capabilities & limits: hallucination, knowledge cutoff, bias

## Prompting Basics

- [ ] **Phase 6** — Prompt anatomy: system, user, assistant messages
- [ ] **Phase 7** — Clear instructions: specificity, constraints, audience
- [ ] **Phase 8** — Output formats: JSON, tables, lists, schemas
- [ ] **Phase 9** — Zero-shot prompting: direct tasks, defaults
- [ ] **Phase 10** — Few-shot prompting: examples, formatting, selection
- [ ] **Phase 11** — Common pitfalls: vagueness, contradictions, overloading

## Advanced Prompting

- [ ] **Phase 12** — Chain-of-thought: reasoning steps, intermediate results
- [ ] **Phase 13** — Decomposition: subtasks, planning, hierarchical prompts
- [ ] **Phase 14** — Role prompting: personas, expertise, perspective
- [ ] **Phase 15** — Structured reasoning: step-by-step instructions, verification
- [ ] **Phase 16** — Iterative refinement: revise, critique, improve cycles
- [ ] **Phase 17** — Prompt chaining: sequential outputs, pipelines

## Context Engineering

- [ ] **Phase 18** — Context selection: relevant information, pruning
- [ ] **Phase 19** — Compression: summaries, extraction, truncation
- [ ] **Phase 20** — Ordering: recency effects, priority placement
- [ ] **Phase 21** — Retrieval grounding: RAG, citations, verification
- [ ] **Phase 22** — Memory: conversation history, persistence, state

## Tool Use & Agents

- [ ] **Phase 23** — Function calling: tool schemas, arguments, execution
- [ ] **Phase 24** — Tool design: capabilities, names, error handling
- [ ] **Phase 25** — Agent loops: plan, act, observe, iterate
- [ ] **Phase 26** — Multi-step tasks: state tracking, intermediate outputs
- [ ] **Phase 27** — Frameworks: LangChain, LangGraph, assistants APIs

## Production Prompting

- [ ] **Phase 28** — Prompt versioning: tracking, diffs, rollbacks
- [ ] **Phase 29** — Templates: variables, conditionals, localization
- [ ] **Phase 30** — Evaluation: criteria, scoring, A/B comparisons
- [ ] **Phase 31** — Monitoring: quality drift, logs, feedback
- [ ] **Phase 32** — Cost optimization: caching, routing, length control

## Specialized Domains

- [ ] **Phase 33** — Code generation: languages, tests, debugging prompts
- [ ] **Phase 34** — Data extraction: entities, schemas, transformation
- [ ] **Phase 35** — Summarization: lengths, focus, faithfulness
- [ ] **Phase 36** — Creative writing: style, tone, structure, iteration
- [ ] **Phase 37** — Reasoning tasks: math, logic, puzzles, checks

## Evaluation & Testing

- [ ] **Phase 38** — Test sets: representative, edge cases, regressions
- [ ] **Phase 39** — Metrics: accuracy, completeness, format validity
- [ ] **Phase 40** — Evals: automated grading, model-as-judge, humans
- [ ] **Phase 41** — Red teaming: adversarial prompts, robustness

## Ethics & Safety

- [ ] **Phase 42** — Prompt injection: detection, defenses, sandboxing
- [ ] **Phase 43** — Bias & fairness: harmful outputs, mitigation
- [ ] **Phase 44** — Responsible use: privacy, disclosure, misuse prevention

## Career & Practice

- [ ] **Phase 45** — Portfolio: prompt libraries, case studies, evals
- [ ] **Phase 46** — Use cases: workflows, products, automation
- [ ] **Phase 47** — Continuous learning: research, communities, experimentation

## Recommended Learning Path (priority order)

1. **Phase 1–5** — LLM fundamentals
2. **Phase 6–11** — Prompting basics
3. **Phase 12–17** — Advanced prompting
4. **Phase 18–22** — Context engineering
5. **Phase 23–27** — Tool use & agents
6. **Phase 38–41** — Evaluation & testing
7. **Phase 42–44** — Ethics & safety
