# QA Engineer Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with QA-specific context.

## Testing Fundamentals (Prerequisites)

- [ ] **Phase 1** — Testing basics: what, why, costs, quality vs speed
- [ ] **Phase 2** — SDLC & STLC: phases, test involvement, shift-left
- [ ] **Phase 3** — Test levels: unit, integration, system, acceptance, regression
- [ ] **Phase 4** — Requirements analysis: review, gaps, testability, acceptance criteria

## Test Design & Techniques

- [ ] **Phase 5** — Test case design: steps, preconditions, expected results, priority
- [ ] **Phase 6** — Equivalence & boundaries: partitions, boundary values, edge cases
- [ ] **Phase 7** — State & scenario techniques: state transition, use case flows, decision tables
- [ ] **Phase 8** — Pairwise & combinatorial: orthogonal arrays, coverage tradeoffs
- [ ] **Phase 9** — Exploratory testing: charter-based, heuristics, session notes
- [ ] **Phase 10** — Risk-based testing: severity, likelihood, prioritization

## Test Management

- [ ] **Phase 11** — Test plans: scope, strategy, schedule, entry/exit criteria
- [ ] **Phase 12** — Traceability: requirements mapping, coverage tracking
- [ ] **Phase 13** — Defect lifecycle: reporting, triage, severity vs priority, retest
- [ ] **Phase 14** — Reporting: dashboards, metrics, status summaries, sign-off

## Manual Testing

- [ ] **Phase 15** — Functional testing: happy path, negative, corner cases
- [ ] **Phase 16** — UI/UX testing: usability, consistency, responsiveness
- [ ] **Phase 17** — Cross-browser testing: engines, devices, responsive checks
- [ ] **Phase 18** — Regression testing: smoke, sanity, full suites, selection

## Web Automation

- [ ] **Phase 19** — Automation fundamentals: when to automate, ROI, pyramid
- [ ] **Phase 20** — Selenium: WebDriver, browsers, grids, limitations
- [ ] **Phase 21** — Playwright & Cypress: test runner, fixtures, assertions
- [ ] **Phase 22** — Locators & waits: selectors, explicit waits, retries
- [ ] **Phase 23** — Page Object Model: abstraction, reuse, maintenance
- [ ] **Phase 24** — Data-driven & fixtures: parameterization, environments, setup

## API Testing

- [ ] **Phase 25** — API fundamentals: HTTP methods, status codes, payloads, headers
- [ ] **Phase 26** — Postman: collections, variables, assertions, environments
- [ ] **Phase 27** — REST testing: schemas, contract checks, error scenarios
- [ ] **Phase 28** — Auth testing: tokens, OAuth flows, authorization gaps
- [ ] **Phase 29** — API automation: supertest, REST Assured, CI integration

## Performance Testing

- [ ] **Phase 30** — Performance concepts: load, stress, soak, spikes, baselines
- [ ] **Phase 31** — JMeter: thread groups, samplers, assertions, reports
- [ ] **Phase 32** — Load testing: scenarios, ramp-ups, virtual users, thresholds
- [ ] **Phase 33** — Profiling basics: response times, bottlenecks, resource usage

## Mobile & Specialized Testing

- [ ] **Phase 34** — Mobile testing: platforms, gestures, network conditions
- [ ] **Phase 35** — Device testing: emulators, simulators, device farms
- [ ] **Phase 36** — Accessibility testing: WCAG, screen readers, keyboard nav
- [ ] **Phase 37** — Security testing basics: OWASP checks, injection, auth flaws

## CI/CD & Automation Practices

- [ ] **Phase 38** — CI integration: pipelines, scheduled runs, reporting
- [ ] **Phase 39** — Test environments: staging, sandbox, data setup, containers
- [ ] **Phase 40** — Test data management: factories, seeding, isolation
- [ ] **Phase 41** — Flaky test management: stabilization, quarantine, retries
- [ ] **Phase 42** — BDD: Gherkin, Cucumber, behavior specifications

## Career & Soft Skills

- [ ] **Phase 43** — Communication: triage facilitation, pairing, clear reporting
- [ ] **Phase 44** — Bug reporting: reproduction steps, evidence, clarity
- [ ] **Phase 45** — Documentation: test docs, checklists, knowledge sharing
- [ ] **Phase 46** — Agile ceremonies: standups, grooming, sprint testing
- [ ] **Phase 47** — Career growth: automation depth, quality advocacy, tooling

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Testing fundamentals
2. **Phase 5–10** — Test design techniques
3. **Phase 15–18** — Manual testing
4. **Phase 19–24** — Web automation
5. **Phase 25–29** — API testing
6. **Phase 38–42** — CI/CD practices
7. **Phase 43–47** — Career skills

> Focus on building real projects — employers hire mid-level QA engineers for clean, reliable, well-tested releases plus ownership of quality end-to-end.
