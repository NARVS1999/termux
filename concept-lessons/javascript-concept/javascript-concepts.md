# JavaScript Concept Hierarchy

## Foundational Concepts

1. Variables — basic — ang lalagyan ng data gamit ang let, const, var
2. Data Types — basic — ang mga uri ng data gaya ng string, number, boolean
3. Operators — basic — ang mga symbol para sa math at comparison
4. String Methods — basic — ang mga built-in na function para sa text
5. Number Methods — basic — ang mga built-in na function para sa numbers
6. Type Coercion — intermediate — ang automatic na pag-convert ng data types
7. Template Literals — basic — ang pag-interpolate ng variables sa string
8. Comments — basic — ang mga notes na hindi pinapatakbo

## Core Concepts

1. Functions — basic — ang reusable block ng code na may parameter at return
2. Arrow Functions — basic — ang shorter na syntax ng functions
3. Scope — intermediate — ang visibility ng variables sa iba't ibang parte ng code
4. Closures — advanced — ang function na naalala ang sariling lexical scope
5. Hoisting — intermediate — ang pag-move ng declarations sa top ng scope
6. Callbacks — intermediate — ang function na pinapasa bilang argument
7. Promises — intermediate — ang representation ng future na value
8. Async/Await — intermediate — ang cleaner na syntax para sa asynchronous code
9. Error Handling — intermediate — ang paghawak ng errors gamit ang try-catch
10. Strict Mode — basic — ang stricter na rules para sa JavaScript execution

## Implementation Concepts

1. Arrays — basic — ang ordered na list ng values
2. Array Methods — intermediate — ang map, filter, reduce at iba pa
3. Objects — basic — ang key-value pairs na nagre-represent ng entity
4. Destructuring — intermediate — ang pag-extract ng values mula sa arrays o objects
5. Spread & Rest Operators — intermediate — ang pag-copy o pag-gather ng values
6. Modules — intermediate — ang paghihiwalay ng code sa separate files
7. Classes — intermediate — ang blueprint para sa objects gamit ang OOP
8. Prototypes — advanced — ang inheritance mechanism ng JavaScript
9. Symbol — intermediate — ang unique na primitive value
10. Iterators & Generators — advanced — ang custom na iteration protocol

## Integration Concepts

1. DOM Manipulation — intermediate — ang pagbago ng HTML elements gamit ang JavaScript
2. Event Listeners — intermediate — ang pag-react sa user actions gaya ng click
3. Event Delegation — advanced — ang pag-handle ng events sa parent para sa efficiency
4. Fetch API — intermediate — ang paggawa ng HTTP requests sa server
5. AJAX — intermediate — ang pag-load ng data nang hindi nagre-refresh ng page
6. Local Storage — basic — ang pag-iimbak ng data sa browser
7. JSON — basic — ang standard na format para sa data exchange
8. Web APIs — intermediate — ang mga built-in na APIs ng browser

## Architectural Concepts

1. Functional Programming — intermediate — ang paggawa ng code gamit ang pure functions
2. Imperative vs Declarative — intermediate — ang pagkakaiba ng how at what
3. First-Class Functions — basic — ang functions bilang values na pwedeng i-pass
4. Higher-Order Functions — intermediate — ang functions na tumatanggap ng functions
5. Recursion — intermediate — ang function na tumatawag sa sarili
6. Memoization — advanced — ang caching ng function results para sa speed
7. Composition — advanced — ang pagbubuo ng functions mula sa mas maliliit na functions
8. Immutable Data — intermediate — ang pag-iwas ng data mutation

## Design Concepts

1. Design Patterns — advanced — ang proven na solusyon sa common na problema
2. Singleton — intermediate — ang pattern na may isang instance lang
3. Factory — intermediate — ang pattern na nagre-create ng objects
4. Observer — intermediate — ang pattern na nagno-notify ng changes
5. Module Pattern — intermediate — ang pag-encapsulate ng private state
6. MVC Pattern — intermediate — ang paghihiwalay ng model, view, at controller
7. Pub/Sub — intermediate — ang communication pattern gamit ang events
8. Strategy — advanced — ang pattern na nagpapalit ng algorithm runtime

## Advanced Concepts

1. Event Loop — advanced — ang mechanism ng JavaScript para sa async execution
2. Call Stack — intermediate — ang tracking ng function executions
3. Microtasks & Macrotasks — advanced — ang priority ng async operations
4. Web Workers — advanced — ang parallel processing sa background thread
5. Service Workers — advanced — ang proxy para sa caching at offline support
6. Proxy & Reflect — advanced — ang custom na behavior ng objects
7. WeakRef & FinalizationRegistry — advanced — ang memory management techniques
8. Shared Memory & Atomics — advanced — ang concurrency sa multiple threads

## Production Concepts

1. Transpilation — intermediate — ang pag-convert ng modern JS sa older version
2. Bundling — intermediate — ang pag-combine ng multiple files sa isang bundle
3. Minification — basic — ang pagliit ng file size sa pamamagitan ng pagbawas ng whitespace
4. Tree Shaking — advanced — ang pagtanggal ng unused code
5. Code Splitting — advanced — ang paghahati ng code sa smaller chunks
6. Lazy Loading — intermediate — ang pag-load ng resources kapag kailangan lang
7. Polyfills — intermediate — ang pagdagdag ng features sa older browsers
8. Source Maps — intermediate — ang pag-trace ng minified code sa original

## Optimization Concepts

1. Debouncing — intermediate — ang pag-delay ng function execution
2. Throttling — intermediate — ang pag-limit ng function execution frequency
3. requestAnimationFrame — intermediate — ang smooth na animations sa browser
4. Virtual Scrolling — advanced — ang pag-render lang ng visible items
5. Memory Leak Prevention — advanced — ang pag-iwas ng hindi na-garbage collect na data
6. Profiling — intermediate — ang pag-analyze ng performance ng JavaScript code
7. Bundle Analysis — intermediate — ang pagtingin ng bundle size breakdown
8. JIT Compilation — advanced — ang just-in-time na optimization ng JavaScript engine

## Expert/Strategic Concepts

1. V8 Engine Internals — advanced — ang loob ng JavaScript engine ng Chrome
2. Garbage Collection — advanced — ang automatic na memory management
3. Prototypal Inheritance — advanced — ang deep understanding ng prototype chain
4. Metaprogramming — advanced — ang pag-manipulate ng code behavior
5. WASM Integration — advanced — ang paggamit ng WebAssembly sa JavaScript
6. Isomorphic JavaScript — advanced — ang pagtakbo ng code sa server at client
7. AST Manipulation — advanced — ang pagbago ng code structure gamit ang abstract syntax tree
8. Compiler Optimizations — advanced — ang understanding ng JavaScript optimizations
9. Security Best Practices — advanced — ang pagprotekta ng JavaScript code laban sa attacks
