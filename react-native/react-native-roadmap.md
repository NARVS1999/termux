# React Native Developer Roadmap: Fundamentals → Intermediate

> General knowledge for mobile developers, with React Native-specific context.

## Prerequisites

- [ ] **Phase 1** — JavaScript & TypeScript: types, async, ES modules
- [ ] **Phase 2** — React basics: components, props, state, hooks
- [ ] **Phase 3** — Mobile concepts: platforms, gestures, lifecycle differences
- [ ] **Phase 4** — Dev environment: Node, simulators, devices, tooling

## React Native Fundamentals

- [ ] **Phase 5** — Project setup: Expo vs CLI, init, structure
- [ ] **Phase 6** — Core components: View, Text, Pressable, ScrollView, FlatList
- [ ] **Phase 7** — State & props: useState, lifting, derived state
- [ ] **Phase 8** — Styling: StyleSheet, layout, flexbox, dimensions
- [ ] **Phase 9** — Lists: FlatList, SectionList, keys, performance props
- [ ] **Phase 10** — Platform differences: Platform.select, iOS vs Android APIs

## Navigation & UX

- [ ] **Phase 11** — Navigation: React Navigation, stack, tabs, drawer
- [ ] **Phase 12** — Navigation patterns: params, nesting, linking, auth flows
- [ ] **Phase 13** — Deep linking: schemes, universal links, linking config
- [ ] **Phase 14** — Gestures & touch: gesture responders, Gesture Handler
- [ ] **Phase 15** — Safe areas & responsive: safe area context, breakpoints, orientation

## State Management

- [ ] **Phase 16** — Context: providers, consumers, limits
- [ ] **Phase 17** — Global state: Zustand, Redux Toolkit, selectors
- [ ] **Phase 18** — Server state: React Query, caching, mutations
- [ ] **Phase 19** — Persistence: AsyncStorage, MMKV, state rehydration

## Networking & Data

- [ ] **Phase 20** — HTTP: fetch, axios, timeouts, error handling
- [ ] **Phase 21** — Image loading: caching, placeholders, resize modes
- [ ] **Phase 22** — Local storage: SQLite, WatermelonDB, file storage
- [ ] **Phase 23** — Offline support: queues, sync, conflict resolution
- [ ] **Phase 24** — WebSockets & realtime: sockets, presence, updates

## Native Features

- [ ] **Phase 25** — Permissions: permission APIs, rationale, platforms
- [ ] **Phase 26** — Camera & media: capture, picker, library access
- [ ] **Phase 27** — Location: geolocation, background, permissions
- [ ] **Phase 28** — Notifications: push, local, channels, scheduling
- [ ] **Phase 29** — Native modules: bridging, TurboModules, libraries
- [ ] **Phase 30** — Device features: haptics, clipboard, share, sensors

## Styling & Animations

- [ ] **Phase 31** — Theming: themes, tokens, dark mode
- [ ] **Phase 32** — Animations: Animated API, Reanimated, transitions
- [ ] **Phase 33** — Advanced views: SVG, maps, WebView
- [ ] **Phase 34** — Design systems: component libraries, consistency

## Testing & Debugging

- [ ] **Phase 35** — Unit tests: Jest, testing utilities, mocks
- [ ] **Phase 36** — Component tests: React Native Testing Library
- [ ] **Phase 37** — E2E tests: Detox, Maestro, device testing
- [ ] **Phase 38** — Debugging: React DevTools, network, logs, error boundaries

## Performance

- [ ] **Phase 39** — Rendering: re-renders, memoization, list perf
- [ ] **Phase 40** — Memory: leaks, large lists, image memory
- [ ] **Phase 41** — Startup: initialization, lazy loading, bundles
- [ ] **Phase 42** — Profiling: profiler, tools, measuring improvements

## Publishing & Operations

- [ ] **Phase 43** — Building: signing, keystores, release configs
- [ ] **Phase 44** — Store publishing: App Store, Play Store, listing
- [ ] **Phase 45** — Updates: OTA updates, Expo Updates, versioning
- [ ] **Phase 46** — Crash reporting: Sentry, logs, alerts
- [ ] **Phase 47** — CI/CD: pipelines, builds, testing, distribution

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Prerequisites
2. **Phase 5–10** — RN fundamentals
3. **Phase 11–15** — Navigation & UX
4. **Phase 16–19** — State management
5. **Phase 25–30** — Native features
6. **Phase 35–38** — Testing & debugging
7. **Phase 43–47** — Publishing & operations

> Focus on building real projects — employers hire mid-level React Native devs for clean, performant, well-tested code plus ownership of features end-to-end.
