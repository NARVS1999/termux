# UX Designer Roadmap: Fundamentals → Intermediate

> General knowledge for designers, with UX-specific context.

## UX Fundamentals (Prerequisites)

- [ ] **Phase 1** — What is UX: definitions, scope, value, career landscape
- [ ] **Phase 2** — Design thinking: empathize, define, ideate, prototype, test
- [ ] **Phase 3** — UX process: discover, define, develop, deliver phases
- [ ] **Phase 4** — Psychology basics: mental models, cognitive load, motivation

## User Research

- [ ] **Phase 5** — Research planning: goals, methods, participants, logistics
- [ ] **Phase 6** — Interviews: scripts, moderation, probing, synthesis
- [ ] **Phase 7** — Surveys & questionnaires: design, sampling, interpretation
- [ ] **Phase 8** — Usability tests: tasks, observation, findings, severity
- [ ] **Phase 9** — Analytics & logs: behavioral data, funnels, segmentation
- [ ] **Phase 10** — Synthesis: affinity mapping, insights, journey maps, personas

## Information Architecture

- [ ] **Phase 11** — IA principles: organization, labeling, findability
- [ ] **Phase 12** — Card sorting: open vs closed, analysis, groupings
- [ ] **Phase 13** — Sitemaps & taxonomies: hierarchy, naming, categories
- [ ] **Phase 14** — Navigation design: global, local, contextual, search
- [ ] **Phase 15** — Content strategy: tone, structure, readiness, governance

## Interaction Design

- [ ] **Phase 16** — User flows: task flows, decision trees, error paths
- [ ] **Phase 17** — Interface states: default, hover, loading, empty, error
- [ ] **Phase 18** — Feedback & affordances: cues, responses, confirmation
- [ ] **Phase 19** — Micro-interactions: triggers, rules, feedback, loops
- [ ] **Phase 20** — Prototyping interactions: transitions, animations, gestures

## Wireframing & Prototyping

- [ ] **Phase 21** — Wireframing: lo-fi, mid-fi, annotations, scope
- [ ] **Phase 22** — Fidelity choices: when each level fits the question
- [ ] **Phase 23** — Figma: frames, components, autolayout, variants
- [ ] **Phase 24** — Clickable prototypes: flows, logic, device frames
- [ ] **Phase 25** — Design handoff: specs, assets, developer collaboration

## Usability & Testing

- [ ] **Phase 26** — Heuristic evaluation: Nielsen's heuristics, scoring
- [ ] **Phase 27** — Usability testing: moderation, metrics, report writing
- [ ] **Phase 28** — Accessibility testing: screen readers, keyboard, contrast
- [ ] **Phase 29** — A/B & preference testing: hypotheses, variants, validity
- [ ] **Phase 30** — UX metrics: task success, SUS, time-on-task, error rates

## Visual Design Basics

- [ ] **Phase 31** — Layout: grids, spacing, alignment, composition
- [ ] **Phase 32** — Typography: hierarchy, readability, scale
- [ ] **Phase 33** — Color: palettes, contrast, meaning, usage
- [ ] **Phase 34** — Visual hierarchy: emphasis, scanning, grouping

## Product & Business

- [ ] **Phase 35** — Problem framing: problem statements, success criteria
- [ ] **Phase 36** — Requirements: user stories, acceptance criteria, constraints
- [ ] **Phase 37** — Product metrics: KPIs, impact, iteration planning
- [ ] **Phase 38** — Stakeholders: alignment, presenting, decision making
- [ ] **Phase 39** — Agile & design ops: sprints, critiques, rituals

## Accessibility & Inclusion

- [ ] **Phase 40** — WCAG: levels, criteria, conformance
- [ ] **Phase 41** — Inclusive design: personas, edge cases, bias awareness
- [ ] **Phase 42** — Assistive technology: screen readers, magnification, switch
- [ ] **Phase 43** — Accessible content: plain language, labels, alt text

## Career & Portfolio

- [ ] **Phase 44** — Case studies: process narratives, outcomes
- [ ] **Phase 45** — Portfolio: curation, presentation, feedback
- [ ] **Phase 46** — Interviews: portfolio reviews, exercises, culture fit
- [ ] **Phase 47** — Continuous learning: community, reading, mentorship

## Recommended Learning Path (priority order)

1. **Phase 1–4** — UX fundamentals
2. **Phase 5–10** — User research
3. **Phase 11–15** — Information architecture
4. **Phase 16–20** — Interaction design
5. **Phase 21–25** — Wireframing & prototyping
6. **Phase 26–30** — Usability & testing
7. **Phase 44–47** — Career & portfolio

> Focus on building real projects — employers hire mid-level UX designers for clean, usable, well-researched products plus ownership of experiences end-to-end.
