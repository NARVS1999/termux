# Shell & Bash Roadmap: Fundamentals → Intermediate

> General knowledge for DevOps engineers, with shell-specific context.

## Shell Fundamentals (Prerequisites)

- [ ] **Phase 1** — What is a shell: interpreters, login vs non-login
- [ ] **Phase 2** — Terminal basics: prompts, shortcuts, history, autocomplete
- [ ] **Phase 3** — Shells: bash vs zsh, POSIX, default shells
- [ ] **Phase 4** — Command structure: commands, options, arguments
- [ ] **Phase 5** — Getting help: man pages, help flags, tldr

## Files & Directories

- [ ] **Phase 6** — Navigation: pwd, cd, ls, paths, globbing
- [ ] **Phase 7** — File operations: touch, cp, mv, rm, mkdir
- [ ] **Phase 8** — Permissions: chmod, chown, umask, special bits
- [ ] **Phase 9** — Links: hard vs symbolic, ln, inodes
- [ ] **Phase 10** — Finding files: find, locate, globs, patterns

## Text Processing

- [ ] **Phase 11** — Reading text: cat, less, head, tail, more
- [ ] **Phase 12** — grep: patterns, recursive, context, -E
- [ ] **Phase 13** — sed: substitution, ranges, in-place edits
- [ ] **Phase 14** — awk: fields, printing, patterns, processing
- [ ] **Phase 15** — Sorting & unique: sort, uniq, options
- [ ] **Phase 16** — Transform: cut, tr, wc, paste, join

## Pipes & Redirection

- [ ] **Phase 17** — Streams: stdin, stdout, stderr
- [ ] **Phase 18** — Redirection: >, >>, 2>, here docs, here strings
- [ ] **Phase 19** — Pipes: chaining, filters, pipeline design
- [ ] **Phase 20** — Process substitution: <(), >(), advanced usage

## Processes & Jobs

- [ ] **Phase 21** — Process management: ps, top, kill, priority
- [ ] **Phase 22** — Job control: background, foreground, jobs, fg/bg
- [ ] **Phase 23** — Signals: types, trapping, cleanup
- [ ] **Phase 24** — System monitoring: free, df, uptime, load
- [ ] **Phase 25** — Daemons & services: systemd, service management

## Environment & Config

- [ ] **Phase 26** — Environment variables: export, common vars, expansion
- [ ] **Phase 27** — Shell configs: .bashrc, .profile, login behavior
- [ ] **Phase 28** — Aliases & functions: creating, persisting, overriding
- [ ] **Phase 29** — PATH & lookup: order, updating, troubleshooting

## Scripting Basics

- [ ] **Phase 30** — Script structure: shebang, permissions, execution
- [ ] **Phase 31** — Variables & arguments: $1, $@, $#, defaults
- [ ] **Phase 32** — Conditionals: if, test, [[ ]], case
- [ ] **Phase 33** — Loops: for, while, until, iteration patterns
- [ ] **Phase 34** — Exit codes: checking, setting, error propagation
- [ ] **Phase 35** — Error handling: set -e, traps, validation

## Advanced Scripting

- [ ] **Phase 36** — Arrays & strings: indexing, slicing, manipulation
- [ ] **Phase 37** — Functions: defining, scoping, returning values
- [ ] **Phase 38** — Command substitution: $(), evaluation order
- [ ] **Phase 39** — Arithmetic: expressions, increment, arithmetic expansion
- [ ] **Phase 40** — Debugging: set -x, bash -n, trace output

## Automation & Practical Skills

- [ ] **Phase 41** — Scheduling: cron, at, script automation
- [ ] **Phase 42** — Git in shell: aliases, helpers, scripting workflows
- [ ] **Phase 43** — Watching files: inotify, loops, watch command
- [ ] **Phase 44** — Network tools: curl, ssh, scp, nc basics

## Career & Practice

- [ ] **Phase 45** — Scripting best practices: naming, comments, modularity
- [ ] **Phase 46** — Portability: POSIX vs bashisms, cross-platform
- [ ] **Phase 47** — Portfolio projects: automation, tooling, runbooks

## Recommended Learning Path (priority order)

1. **Phase 1–5** — Shell fundamentals
2. **Phase 6–10** — Files & directories
3. **Phase 11–16** — Text processing
4. **Phase 17–20** — Pipes & redirection
5. **Phase 30–35** — Scripting basics
6. **Phase 36–40** — Advanced scripting
7. **Phase 41–44** — Automation & practical skills

> Focus on building real projects — employers hire mid-level DevOps engineers for clean, robust, well-tested scripts plus ownership of automation end-to-end.
