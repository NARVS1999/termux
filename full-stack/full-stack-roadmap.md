# Full-Stack Developer Roadmap: Fundamentals → Intermediate

> General knowledge for software developers, with full-stack-specific context.

## Internet & Web Fundamentals (Prerequisites)

- [ ] **Phase 1** — How the web works: HTTP/HTTPS, request-response cycle, status codes, headers
- [ ] **Phase 2** — DNS & browsers: domain resolution, rendering pipeline, devtools
- [ ] **Phase 3** — REST API basics: endpoints, methods, JSON, resource modeling
- [ ] **Phase 4** — Git & tooling: terminal basics, git workflows, package managers

## Frontend Foundations

- [ ] **Phase 5** — HTML semantics: semantic tags, forms, inputs, accessibility attributes
- [ ] **Phase 6** — CSS layout: box model, Flexbox, CSS Grid, positioning, responsive design
- [ ] **Phase 7** — JavaScript basics: variables, types, operators, control flow, functions
- [ ] **Phase 8** — DOM & events: manipulation, listeners, event delegation, bubbling
- [ ] **Phase 9** — ES6+ features: destructuring, spread/rest, arrow functions, modules, classes
- [ ] **Phase 10** — Async JS: promises, async/await, fetch, error handling

## Frontend Framework

- [ ] **Phase 11** — React basics: JSX, components, props, state, conditional rendering
- [ ] **Phase 12** — React hooks: useState, useEffect, useRef, custom hooks
- [ ] **Phase 13** — Client-side routing: React Router, dynamic routes, protected routes
- [ ] **Phase 14** — State management: context, Zustand/Redux, server state with TanStack Query
- [ ] **Phase 15** — Styling in React: Tailwind CSS, CSS Modules, component libraries

## Backend Foundations

- [ ] **Phase 16** — Node.js basics: runtime, modules, npm scripts, environment variables
- [ ] **Phase 17** — Express: routing, middleware, request handling, error handling
- [ ] **Phase 18** — REST API development: CRUD endpoints, validation, pagination
- [ ] **Phase 19** — Authentication: JWT, sessions, bcrypt hashing, refresh tokens
- [ ] **Phase 20** — Authorization: roles, permissions, middleware guards, RBAC
- [ ] **Phase 21** — Backend architecture: layering, services, repositories, config management

## Databases

- [ ] **Phase 22** — SQL basics: SELECT, WHERE, JOINs, GROUP BY, aggregations
- [ ] **Phase 23** — Database design: normalization, relationships, constraints, indexes
- [ ] **Phase 24** — PostgreSQL in depth: data types, transactions, vacuum, extensions
- [ ] **Phase 25** — MongoDB: documents, collections, queries, aggregation pipeline
- [ ] **Phase 26** — ORMs: Prisma, Drizzle, Sequelize, migrations, seeds
- [ ] **Phase 27** — Transactions & concurrency: ACID, isolation levels, locking

## Full-Stack Integration

- [ ] **Phase 28** — API design best practices: naming, versioning, error formats, rate limiting
- [ ] **Phase 29** — Environment & config: env files, validation, secrets, feature flags
- [ ] **Phase 30** — File uploads: multipart, storage options, validation, serving files
- [ ] **Phase 31** — Realtime features: WebSockets, Socket.io, SSE, presence
- [ ] **Phase 32** — Caching: HTTP caching, Redis basics, query caching, CDNs

## Testing & Quality

- [ ] **Phase 33** — Unit testing: Vitest/Jest, assertions, mocking, coverage
- [ ] **Phase 34** — API testing: supertest, integration tests, test databases
- [ ] **Phase 35** — Frontend testing: Testing Library, component and E2E tests
- [ ] **Phase 36** — Debugging & profiling: devtools, logs, Node inspector, tracing

## DevOps & Deployment

- [ ] **Phase 37** — Hosting platforms: Vercel, Railway, Fly.io, AWS basics
- [ ] **Phase 38** — CI/CD: GitHub Actions, pipelines, automated tests and deploys
- [ ] **Phase 39** — Docker basics: images, containers, Dockerfiles, compose
- [ ] **Phase 40** — Monitoring & observability: logs, metrics, error tracking, uptime
- [ ] **Phase 41** — Performance: Core Web Vitals, bundle size, DB query tuning

## Security & Best Practices

- [ ] **Phase 42** — Web vulnerabilities: XSS, CSRF, SQL injection, SSRF, mitigations
- [ ] **Phase 43** — HTTPS & CORS: TLS, headers, CORS policies, CSP
- [ ] **Phase 44** — Secure auth: password hashing, OAuth flows, session fixation, rate limiting

## Career & Soft Skills

- [ ] **Phase 45** — Code review: giving feedback, reviewing pull requests, standards
- [ ] **Phase 46** — Documentation: READMEs, API docs, runbooks, comment discipline
- [ ] **Phase 47** — Project architecture: monorepos, feature structure, tech stack decisions

## Recommended Learning Path (priority order)

1. **Phase 1–4** — Web & git fundamentals
2. **Phase 5–10** — Frontend foundations
3. **Phase 16–18** — Node.js & Express
4. **Phase 22–24** — SQL & PostgreSQL
5. **Phase 11–14** — React & state
6. **Phase 19–20** — Auth & security
7. **Phase 37–39** — Deployment & CI/CD

> Focus on building real projects — employers hire mid-level full-stack engineers for clean, performant, well-tested code plus ownership of features end-to-end.
